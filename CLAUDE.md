# Семейное древо — правила для ИИ-помощника

Этот файл читают Claude Code (`CLAUDE.md`) и Codex (`AGENTS.md`); содержание одинаковое. Меняешь один — повтори правку во втором.

Проект: личная родословная владельца. Цель — найти предков как можно глубже и показать родным сайтом (древо, карточка человека, карта мест, журнал поиска). Владелец не программист: говори с ним простым языком, коротко, суть в первых двух строках, без терминов и путей к файлам, пока не попросит.

## Первым делом в каждой сессии

1. Если `data/config.yaml` всё ещё указывает на тестовую семью (`root: testov-aleksey-1985`) или файла `docs/vision.md` нет — это **первая сессия**. Иди строго по `docs/onboarding.md`.
2. Иначе прочитай `HANDOFF.md` и продолжай с «Следующего шага». Перед новой задачей сверься с `docs/blueprint.md` и отмечай [x] выполненное.
3. Порядок поиска, маршруты по эпохам, сословиям и вере — `method/method.md`. Чему научились на прототипе — `docs/lessons.md`. Обзор источников и архивов России — `docs/research/genealogy-russia.md`.

## Стек

YAML-данные в `data/` → проверка (`npm run validate`, JSON Schema из `schemas/`) → сборка (`npm run build`) → статический сайт Vite + TypeScript, d3-zoom, Leaflet/OpenStreetMap.
Образец всех форматов записей — `tests/fixtures/family/` (выдуманная семья Тестовых). Новые записи пиши по этому образцу и по схемам.

Команды:
- `npm install` — один раз после распаковки;
- `npm run validate` — проверка данных;
- `npm test` — тесты (на тестовой семье и на собранных данных);
- `npm run dev` — сайт на компьютере, открыть адрес, который напишет Vite;
- `npm run build` — собрать сайт в `site/dist/`;
- `npm run build:public` — сборка для показа родным (без личных сканов из `data/private/`).

Код сайта готов и проверен: древо, карточка, карта, журнал, телефонная версия. Без просьбы владельца его не переделывать. Если на его данных что-то выглядит плохо (наложения, пустые места), почини и добавь тест.

## Правила (всегда)

- **Ничего не выдумывать:** ни имён, ни дат, ни архивных шифров, ни адресов архивов. Не знаешь — так и скажи.
- **Каждый факт — с источником** (claim) и уровнем надёжности: `document` / `oral` / `hypothesis` / `conflict`. Рассказ родственника — тоже источник: кто и когда рассказал.
- **Совпадение по имени — гипотеза**, пока нет второго независимого признака: дата, место, имена родных, крёстные.
- **В древо попадает только то, что принял владелец.** Находку сначала показать: что нашли, где (ссылка или шифр), какие признаки совпали, насколько уверены. Принятое — в данные.
- **Каждый поиск — в `data/research/search-log.yaml`**, включая «не нашли»: чтобы не искать дважды.
- Перед коммитом: `npm run validate` и `npm test`. Коммитить по ходу, маленькими осмысленными шагами.
- Конец сессии (владелец пишет «стоп», «всё», «пока») — обнови `HANDOFF.md` по шаблону внутри него и покажи владельцу коротко: что нашли, что ждём, что дальше.

## Спросить сначала

- Новые зависимости (npm-пакеты).
- Изменение схемы данных, которое затрагивает уже внесённые записи.
- Любая выкладка наружу: сервер, ссылка для родных, публичный репозиторий.
- Любые платные действия и отправка писем от имени владельца. Письма в архивы отправляет и оплачивает владелец сам.

## Никогда

- Удалять данные о людях или источниках без явной просьбы.
- Пушить в публичный репозиторий; коммитить `data/media/` и `data/private/` (они в `.gitignore`).
- Вводить в формы паспортные данные, пароли, номера карт: это делает владелец.
- Хранить пароли и ключи в файлах проекта.
