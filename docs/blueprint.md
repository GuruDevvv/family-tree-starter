# Blueprint: семейное древо

Основа: `docs/vision.md`, исследование `docs/research/genealogy-russia.md`.

## Tech Stack
| Слой | Выбор | Почему |
|---|---|---|
| Данные | YAML-файлы в `data/`, по файлу на запись | Claude читает и правит напрямую; история изменений в git; читается человеком |
| Проверка данных | Node.js 20+, `js-yaml`, JSON Schema (`ajv`) | одна схема на тип записи, понятные ошибки |
| Сборка | Node-скрипт `scripts/build` → `site/public/data.json` | сайт не хранит данных, собирается из `data/` |
| Сайт | Vite + TypeScript, без фреймворка; древо на `d3` (или `family-chart`, решить в задаче 6) | статический сайт, открывается локально без сервера |
| Карта | Leaflet + тайлы OpenStreetMap | бесплатно, без ключей |
| Тесты | `vitest` | расчёт родства и дат покрыт тестами |
| Обмен | экспорт GEDCOM 5.5.1 (читают все программы) | не запираем данные в своём формате |
| Показ родным | статическая сборка (`npm run build:public`) на сервере за паролем | только по решению владельца |

Отклонено: Gramps + Gramps Web — медленный ввод через API, нельзя настроить карту/карточку, нужен постоянный сервер.

## Data Model
Все записи ссылаются друг на друга по `id`. Связи (parents, spouses) и события хранятся внутри файла человека; дети вычисляются. Медиа описаны в `data/media.yaml`, сами файлы — в `data/media/`. Образец всех форматов — выдуманная семья в `tests/fixtures/family/`.

| Сущность | Поля |
|---|---|
| **Person** | id; names[] (тип: при рождении / по браку / крестильное / вариант из документа; фамилия, имя, отчество); sex; estate (сословие, может меняться — тогда событием); religion; portrait → media; living: bool; story → stories; tags (ветка) |
| **Relation** | type: parent-child / spouses; from, to; status: confirmed / hypothesis / disputed; alternatives[]; claims[] |
| **Event** | id; type (birth, baptism, marriage, death, burial, residence, move, revision, census, military, award, education, occupation, repression, other); date (см. ниже); place → Place; participants[] {person, role: principal / godparent / witness / spouse / informant / priest}; claims[]; note |
| **Date** | value + qualifier: exact / about / before / after / between(from,to) / estimated; calendar: julian / gregorian (до 1918 — юлианский) |
| **Place** | id; name_then; hierarchy {governorate, uyezd, volost, parish}; name_now; coords {lat, lon, precision: exact / approx}; archive → archives.yaml; period |
| **Source** | id; kind (метрическая книга, ревизская сказка, исповедная ведомость, перепись, ЗАГС, военная база, интервью, домашний документ, …); archive, fond, opis, delo, list; url; media[]; reliability: original / derivative / authored / oral; record_group — общий у копий, перепечаток и индексов одной записи (считаются одним подтверждением) |
| **Claim** | утверждение «что» + «откуда»: source → Source, detail (страница/запись), confidence: document / oral (кто, когда) / hypothesis / conflict; добавлено/принято владельцем: дата |
| **Media** | id; file; kind (photo, portrait, scan, audio); persons[]; source; caption |
| **SearchLogEntry** | date; person; where (база/архив); query; result: found / not_found / partial; claims[] созданные |
| **ArchiveRequest** | id; to (архив); about[] persons; what; sent_date; cost; status: draft / sent / paid / answered / refused; due_date; answer → media/sources |
| **Interview** | id; who; date; questions/answers; claims[] созданные |

Вычисляемое при сборке (не хранится): «кем приходится владельцу», номер предка (Ahnentafel), поколение, лента жизни (события + eras), следующий шаг поиска.

### Правила (проверяет validate)
- у каждого факта о человеке есть claim с источником;
- нет ссылок на несуществующие id;
- ребёнок не старше родителя; возраст матери при рождении 12–55, отца 14–80 (иначе предупреждение);
- неточные даты сравниваются по диапазону;
- тёзки не объединяются без двух независимых признаков (дата, место, родственники).

## Приватность

## Задачи

Код сайта перенесён из прототипа готовым: формат данных и проверка, сборка, древо, карточка, карта, журнал поиска, телефонная версия, методика и шаблоны писем.

```
1. [x] Формат данных и автопроверка — schemas/, scripts/validate
2. [x] Методика, справочник архивов, события эпохи, анкета, шаблоны писем — method/, data/reference/
3. [x] Сборка и сайт: древо, карточка, карта, журнал — scripts/build, site/
```

## Задачи владельца

```
4. [ ] Первая сессия по docs/onboarding.md: видение, данные владельца вместо тестовой семьи
   Готово когда: на сайте древо владельца, validate и тесты проходят

5. [ ] Опрос родных (анкета method/templates/anketa.md), домашний архив
   Готово когда: у старших родственников взяты рассказы, документы отсканированы и описаны

6. [ ] Привязка к месту: для каждого предка село, приход, уезд, губерния и архив-хранитель
   Готово когда: у каждого дальнего предка есть место в data/places с архивом

7. [ ] Первый круг поиска по открытым источникам (method/method.md, раздел 5)
   Готово когда: по каждому предку проверены «Память народа», ОБД, Яндекс-архивы
   и региональные порталы; находки показаны владельцу, принятые на сайте

8. [ ] Первые запросы в ЗАГС и архивы
   Готово когда: 1–3 запроса с проверенным каналом подачи отправлены владельцем

9. [ ] Показ родным (по решению владельца)
   Готово когда: сайт по ссылке с паролем открывается у родственника

10. [ ] Выгрузка GEDCOM 5.5.1 (по желанию)
    Готово когда: файл открывается в Gramps без ошибок
```

## Проверки готовности
1. Открываю сайт → древо со всеми внесёнными людьми видно за ≤3 с; до самого дальнего предка ≤5 кликов.
2. Кликаю на человека → карточка: ФИО и варианты, даты и места, события, портрет или заглушка; у каждого факта источник и уровень надёжности.
3. Открываю карту → точка у каждого человека с известным местом; наведение → портрет и имя; клик → карточка.
4. Даю помощнику новый факт → после одной сборки он в древе, карточке и на карте с пометкой источника.
5. Открываю журнал → по любому предку видно, где искали, итог и следующий шаг; у запросов адресат, дата, стоимость, статус.
6. Вношу ребёнка старше родителя или факт без источника → проверка останавливает сборку с понятной ошибкой.
