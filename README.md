# Семейное древо с ИИ-помощником

Заготовка, чтобы собрать свою родословную вместе с Claude Code или Codex. Это сайт с древом, карточками людей и картой мест, а к нему методика поиска по российским архивам. ИИ-помощник заносит то, что вы знаете, ищет в открытых источниках, готовит письма в архивы и ведёт журнал поиска. Вы приносите рассказы родных и документы, а в древо попадает только то, что вы подтвердили.

*Starter kit for building your family tree with an AI coding agent (Claude Code or Codex). Russian-language docs, focused on Russian and ex-USSR archives.*

## Что внутри

- **Сайт.** Древо с раскрытием боковых веток, карточка человека с событиями, источниками и лентой жизни на фоне эпохи, карта мест, журнал поиска и запросов в архивы, версия для телефона. Собирается в статическую страницу, сервер не нужен.
- **Данные.** Один человек — один YAML-файл. У каждого факта есть источник и уровень надёжности: документ, со слов, догадка или расхождение. Автопроверка ловит факт без источника, ребёнка старше родителя и ссылку на несуществующую запись.
- **Методика.** Порядок работы от себя назад; маршруты по эпохам (ЗАГС, метрики, исповедные ведомости, ревизии), по сословию и вере; открытые источники; анкета для разговора с родными; шаблоны писем в ЗАГС, региональные архивы, ЦАМО, ФСБ и МВД.
- **Инструкция для ИИ.** Файлы `CLAUDE.md` и `AGENTS.md` содержат правила работы. В `docs/onboarding.md` лежит сценарий первой сессии: вопросы к вам, замена примера вашей семьёй, план поиска.

Сейчас в данных выдуманная семья Тестовых, чтобы было видно, как всё выглядит.

## Как начать

1. Установите [Node.js](https://nodejs.org) 20 или новее и одного из помощников: [Claude Code](https://claude.com/claude-code) или [Codex](https://chatgpt.com/codex).
2. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, затем распакуйте.
3. Откройте помощника в этой папке и отправьте ему текст из файла `ПЕРВОЕ-СООБЩЕНИЕ.txt`.

Дальше помощник сам всё установит, покажет сайт с примером и начнёт задавать вопросы о вашей семье. Подробнее в [START-HERE.md](START-HERE.md).

Для разработчиков:

```
npm install
npm run validate   # проверка данных
npm test           # тесты
npm run dev        # сайт на компьютере
npm run build      # сборка в site/dist
```

## Приватность

Ваше древо будет содержать данные живых людей. Если храните его на GitHub, делайте **закрытый** репозиторий: нажмите **Use this template** или скачайте ZIP, но не публикуйте свою копию. Фото и сканы (`data/media/`, `data/private/`) в git не попадают.

## Стек

YAML и JSON Schema (ajv) → Node-скрипт сборки → Vite + TypeScript без фреймворка, d3-zoom, Leaflet и OpenStreetMap, тесты на vitest.
